Como os links são atualizados

Os downloads usam endereços estáveis em temischat/latest/ no CDN oficial. A cada release, esses arquivos e o manifesto são republicados. Por isso, esta página não depende de links do GitHub nem de números de versão fixos nos botões.

Se o manifesto estiver temporariamente indisponível, os links de download permanecem na página. Para confirmar requisitos de sistema e escolher outra arquitetura ou formato, use a seção completa de downloads.
